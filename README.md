# Cryptocurrency Analytics KPI Dashboard

## Project Overview
This project was developed using Microsoft Excel to analyze cryptocurrency market data and generate interactive dashboards.

The project focuses on understanding cryptocurrency performance using various analytical techniques and dashboard visualizations.

---

## Features
• KPI Dashboard  
• Market Analysis  
• Price Change Analysis  
• Liquidity Analysis  
• Coin Comparison  
• Volume Distribution  

---

## Tools Used
• Microsoft Excel  
• Charts and Visualizations  
• Data Analysis Techniques  

---

## Dataset
Cryptocurrency Market Dataset
